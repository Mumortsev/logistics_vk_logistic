# ВК-Логистик

Next.js 15 + TypeScript, Motion, Leaflet/OpenStreetMap, Photon, OSRM, Lucide.

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Откройте http://localhost:3000. Для сборки: `npm run build && npm start`.

## Vercel

Для серверного развёртывания восстановите исходные маршруты и настройте переменные окружения. Конфигурация в репозитории сейчас предназначена для GitHub Pages. Для публикации на GitHub Pages подготовлена статическая демонстрация: поиск и маршруты обращаются к Photon и OSRM из браузера; приём заявок не подключён. Исходные серверные маршруты сохранены в server-api и требуют восстановления в app/api для серверного развёртывания.

## Конфигурация

- `lib/config.ts`: компания, демонстрационные тарифы, коэффициенты, минимальная стоимость.
- `PHOTON_URL`: Photon API, по умолчанию публичный демонстрационный сервер.
- `OSRM_URL`: OSRM API, по умолчанию публичный демонстрационный сервер.
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`: при наличии отправляют заявку в Telegram; без них сервер возвращает 503, а интерфейс показывает ошибку.
- Изображения загружаются с Unsplash, нужны проверка лицензий конкретных изображений и замена на согласованные фирменные фото.

## API

- `GET /api/geocode?q=...` — поиск населённых пунктов с кешированием Next.js.
- `GET /api/route?a=lng,lat&b=lng,lat` — дорожный маршрут и геометрия.
- `POST /api/lead` — отправка заявки, только при настроенном Telegram.

## Перед коммерческим запуском

1. Получить оригинал таблички: точный логотип, телефон, реквизиты, адрес; сверить услуги.
2. Утвердить реальные тарифы, коэффициенты, юридические документы и политику обработки персональных данных.
3. Настроить собственные или коммерческие геокодер, маршрутизатор и тайлы: публичные демо-серверы не гарантируют SLA и могут ограничивать запросы.
4. Подключить приём заявок и защиту от спама (rate limiting, captcha, логирование и политика хранения).
5. Провести полноценные интеграционные и браузерные тесты на целевых устройствах, включая малые населённые пункты, трансграничные маршруты и отказ сервисов.
6. Проверить доступность/корректность географических данных в нужных странах; Photon не гарантирует полноту всей базы СНГ.
